Capability Alignment

Magi Next 对齐 Codex 级工作能力路线

本路线只记录可验证能力，不把工具数量当作成熟度。当前优先级是 memory graph、patch engine、真实评测、goal/plan harness 和工具发现质量。

当前基线

已具备

Agent Loop 和工具执行

已有 provider retry/fallback、stream、tool loop、parallel safe tools、MCP、audit、approval 和 deferred tool reveal。

已增强

Memory Graph v2 起点

Graph edge 已开始参与召回：相关边扩展邻居，supersedes 过滤旧记忆，conflicts_with 抑制间接冲突结果。

仍需补强

真实任务稳定性

当前黑盒测试主要使用 mock provider，能证明 harness 管道，但还不能证明真实 LLM 的复杂任务稳定性。

能力对齐矩阵

能力 目标状态 当前进度 验收证据
Memory Graph 记忆节点、wiki chunk、edge、权重、冲突和替代关系共同决定召回。 进行中 edge-aware retrieval、standalone node search、CLI graph link、MemoryCorrect 纠错闭环、冲突审计视图和可持久配置的长期未用节点降权维护已实现。 tests/memory-node-store.test.ts、tests/rules-memory.test.ts、tests/cli.test.ts、tests/tool-registry.test.ts、scripts/blackbox-e2e.mjs
Patch Engine 用 hunk 级结构化 patch 替代脆弱的 old/new string 编辑。 进行中 FilePatch v1 已支持 unified-diff hunk、唯一上下文匹配、approval diff preview、失败恢复反馈，并把多行编辑优先选择 FilePatch 的策略注入模型上下文。 tests/tool-registry.test.ts、tests/tui-session.test.ts、tests/system-prompt.test.ts、scripts/blackbox-e2e.mjs
Eval Harness 真实模型运行业务级任务，记录成功率、工具效率、回归原因。 进行中 blackbox 已覆盖真实 CLI 的 FilePatch、memory graph link/search、goal、learning、retry/fallback，并输出结构化报告和失败分类。 npm run test:blackbox、tests/harness-report.test.ts；下一步补真实模型任务集和更细评分器。
Goal / Plan Harness 计划、todo、完成审计、阻塞审计由外层状态机维护。 进行中 ExitPlanMode 会持久化 plan review，CLI 可查看最近计划，blackbox 已覆盖 plan visibility。 tests/plan-state.test.ts、tests/tool-registry.test.ts、tests/cli.test.ts、scripts/blackbox-e2e.mjs
Tool Discovery 核心工具常驻，边缘工具可语义搜索、按任务和历史成功率排序。 进行中 ToolSearch 已加入任务意图 ranking、匹配原因、deferred reveal 回放和工具成功/失败反馈加权。 tests/tool-registry.test.ts、scripts/blackbox-e2e.mjs；下一步接入更细的任务类型成功率和失败分类。
TUI / Mobile Control 终端、手机、远程控制能一致处理 stream、approval、cancel 和 resume。 进行中 Control API 已有真实 CLI serve 黑盒覆盖：pairing、SSE、background job、手机审批解锁 FileWrite 和持久审计。 scripts/blackbox-e2e.mjs、tests/control-api.test.ts；下一步补 panel 浏览器 E2E、cancel/resume 手机流程。
