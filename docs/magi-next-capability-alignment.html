Capability Alignment

Magi Next 对齐 Codex 级工作能力路线

本路线只记录可验证能力，不把工具数量当作成熟度。当前优先级是 memory graph、patch engine、真实评测、goal/plan harness 和工具发现质量。

当前基线

已具备

Agent Loop 和工具执行

已有 provider retry/fallback、stream、tool loop、parallel safe tools、MCP、audit、approval 和 deferred tool reveal。

已增强

Memory Graph v2 起点

Graph edge 已开始参与召回和学习：相关边扩展邻居，召回路径会记录 edge 使用次数并提升权重，用户反馈会记录趋势、可查看趋势榜，并强化、降权或纠错节点。

仍需补强

真实任务稳定性

当前主门禁仍以 mock provider 保持稳定；已新增可选 live smoke 入口，用真实模型执行改代码、复测和报告写入任务。
