Capability Alignment

Magi Next 对齐 Codex 级工作能力路线

本路线只记录可验证能力，不把工具数量当作成熟度。当前优先级是 memory graph、patch engine、真实评测、goal/plan harness 和工具发现质量。

当前基线

已具备

Agent Loop 和工具执行

已有 provider retry/fallback、stream、tool loop、parallel safe tools、MCP、audit、approval 和 deferred tool reveal。

已增强

Memory Graph v2 起点

Graph edge 已开始参与召回：相关边扩展邻居，supersedes 过滤旧记忆，conflicts_with 抑制间接冲突结果。

仍需补强

真实任务稳定性

当前黑盒测试主要使用 mock provider，能证明 harness 管道，但还不能证明真实 LLM 的复杂任务稳定性。

Eval Harness 真实模型运行业务级任务，记录成功率、工具效率、回归原因。 进行中 blackbox 已覆盖真实 CLI 的 FilePatch、memory graph link/search、goal、learning、retry/fallback，并输出结构化报告、失败分类、provider 调用效率、断言覆盖、文件验证数、实际工具调用分布和 regression 摘要；model task benchmark 已把项目编辑、记忆驱动输出、工具发现检索，以及跨文件编辑后运行聚焦验证做成固定任务集；capability report 会把这些细粒度评分器和 blackbox、Model Tasks、Memory、Patch Engine、Goal/Plan、Tool Discovery、Control API 门禁一起汇总，并生成跨版本 trend report 跟踪 score、通过项、regression、provider/tool 调用变化。 npm run test:blackbox、npm run test:model-tasks、npm run test:goal-plan-eval、npm run test:tool-discovery-eval、npm run test:control-api-eval、npm run report:capability、.github/workflows/ci.yml、scripts/model-task-benchmark.mjs、tests/harness-report.test.ts、tests/capability-report.test.ts、tests/capability-trend.test.ts、src/capability-trend.ts；下一步扩大真实任务集规模和难度。
Goal / Plan Harness 计划、todo、完成审计、阻塞审计由外层状态机维护。 进行中 ExitPlanMode 会持久化 plan review，CLI 可查看最近计划、跨 session 历史计划、单条 plan 详情和修订链聚合视图；修订和批准后的计划会保存 revises / revised-by / root plan 链路，并在恢复同 session 时把最新计划作为 session plan context 注入模型；approved plan 可被 adopt 到另一个 session 并保留来源链路。独立 goal/plan eval 已覆盖 active goal 注入、completed/blocked 后不注入、plan mode 写入拒绝、plan review 持久化、跨 session plan review 检索、用户要求修订后的 needs_revision 状态、修订计划审批通过后的 approved 状态、修订链路持久化、修订链 CLI 检索、历史计划上下文继承、继承计划驱动的 read-before-write 执行一致性、继承计划偏离时的 guard 纠偏反馈、跨 session plan adopt 和 adopted plan context 注入、blocked audit 和 goal completion。 tests/plan-state.test.ts、tests/tool-registry.test.ts、tests/cli.test.ts、scripts/goal-plan-eval.mjs、scripts/blackbox-e2e.mjs
Tool Discovery 核心工具常驻，边缘工具可语义搜索、按任务和历史成功率排序。 进行中 ToolSearch 已加入任务意图 ranking、匹配原因、deferred reveal 回放，以及按任务意图分组的工具成功/失败反馈加权；独立 tool discovery eval 已覆盖核心/延迟曝光、语义排序、schema reveal、usage feedback 排名、intent-scoped usage 记录、失败分类反馈、恢复建议、独立后续任务中复用历史反馈的跨任务恢复排名，以及长周期多任务下同类任务复用反馈但无关 intent 不被污染。 tests/tool-registry.test.ts、scripts/tool-discovery-eval.mjs、scripts/blackbox-e2e.mjs、npm run report:capability；下一步扩展更长真实使用序列下的工具策略漂移评估。
TUI / Mobile Control 终端、手机、远程控制能一致处理 stream、approval、cancel 和 resume。 进行中 Control API 已有独立真实 CLI serve eval 覆盖：pairing URL/二维码语义、mDNS 网络发现、SSE、background job、手机审批解锁 FileWrite、stream job cancel、active approval cancel、panel session resume、真实 panel HTML/client contract、panel approval/cancel 控制、移动 viewport 浏览器面板发送/流式渲染/取消操作、保存 peer 凭证、ToolSearch reveal Agent 后跨 daemon peer dispatch，以及远端 session/job/audit 持久审计。 scripts/control-api-eval.mjs、scripts/blackbox-e2e.mjs、tests/control-api.test.ts、tests/cli.test.ts、npm run report:capability；下一步补真实手机设备局域网 smoke test 和真实跨机器 peer dispatch benchmark。
